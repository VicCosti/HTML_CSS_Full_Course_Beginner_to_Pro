## 📋 Overview

This lesson covers the fundamental building blocks of HTML: creating interactive elements (buttons), displaying text content (paragraphs), and linking to external resources (anchor tags). The final challenge exercise combines these basics to recreate a simple product card UI, similar to what you'd see on an e-commerce site.

---

## ✅ Exercises

| # | Task | Concept |
|---|------|---------|
| 1a | Create a button with the text "Click" inside | `<button>` element |
| 1b | Create 2 buttons: one with your name, one with your favorite food | Multiple elements, content variation |
| 1c | Create a paragraph with the text "Hello, World!" inside | `<p>` element |
| 1d | Create a paragraph below the previous one with something you did today | Document flow / element ordering |
| 1e | Create a link to google.com (or a similar site for your country) | `<a>` element, `href` attribute |
| 1f | Make the link from 1e open in a new tab | `target="_blank"` attribute |
| 1g 🏆 **Challenge** | Recreate a mini "product card" design — a link, product name, price/stock line, delivery info, and action buttons | Combining elements into a small UI component |

## 🧠 Key Concepts Applied

- **Semantic structure** — using the right HTML element for the right kind of content (`<button>` for actions, `<p>` for text, `<a>` for navigation)
- **Attributes** — using `href` to define link destinations and `target="_blank"` to control link behavior
- **Document flow** — HTML elements render in the order they appear in the source
- **UI composition** — combining several basic elements (text, links, buttons) to recreate a small, realistic interface component

---

## 📚 What I Learned

- How to create and structure basic HTML elements: buttons, paragraphs, and links
- How the `href` attribute defines where a link points, and how `target="_blank"` changes its default behavior
- That even simple elements like buttons and paragraphs can be composed together to build recognizable UI patterns, like a product card
- The importance of clean, readable markup as a foundation before introducing CSS styling
