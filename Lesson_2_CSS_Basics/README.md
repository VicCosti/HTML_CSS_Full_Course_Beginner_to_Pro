## 📋 Overview

This lesson introduces core CSS styling by recreating buttons from real, well-known websites (Uber, Amazon, GitHub, Bootstrap, LinkedIn) using exact colors, dimensions, and border styles. The final challenge exercise builds on the Lesson 1 product card, applying color, font-weight, and font-size to turn the plain HTML structure into a fully styled UI component.

## 🧠 Key Concepts Applied

- **Class-based styling** — using CSS classes to target and style specific buttons and elements independently
- **Color precision** — matching real brand colors using `rgb()` values instead of named colors
- **Box model properties** — controlling `height`, `width`, `border-radius`, and `border` to match each brand's button shape
- **Typography control** — adjusting `font-size` and `font-weight` to match real UI text styling
- **Filled vs. outlined button patterns** — a common UI pattern seen across Bootstrap and LinkedIn (primary action vs. secondary action)

---

## 📚 What I Learned

- How to translate a visual design into precise CSS using `rgb()` color values and box model properties
- The difference in approach between a "filled" button (background color) and an "outlined" button (transparent background, colored border and text)
- How small details — `border-radius`, `font-size`, spacing — are what make a recreated button actually feel like the real brand
- How to apply CSS to an existing HTML structure (the Lesson 1 product card) to progressively improve a project, rather than starting from scratch
